# Illustrations - DOMOVIK

## Required Files

### Civic Tech Identity Illustrations
- **people-collaboration.svg** - Hero section illustration
  - Theme: People working together, civic engagement
  - Format: SVG (scalable, small file size)
  - Colors: Use DOMOVIK brand palette (#006AAF, #C6451F)

- **community.svg** - Footer or banner illustrations
  - Theme: Community, local initiatives
  - Format: SVG
  - Style: Simple, warm, human-centered

## Placeholder Strategy

Current implementation uses placeholders from:
- https://heroicons.com/ (free SVG icons)
- https://undraw.co/ (civic tech themed illustrations)

## Design Guidelines

**Style:**
- Clean, simple lines
- Warm, approachable aesthetic
- Civic Tech identity (people-focused, not tech-focused)
- Avoid corporate/sterile look

**Colors:**
- Primary: #006AAF (DOMOVIK blue)
- Accent: #C6451F (DOMOVIK orange)
- Neutrals: #F5F5F0, #FFF8F0

**Format:**
- SVG preferred (scalable, small size)
- Optimize with SVGO or similar tools
- Max size: 50KB per file
