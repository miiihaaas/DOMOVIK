# Logo Assets - DOMOVIK

## Required Files

### Primary Branding
- **domovik-logo.png** (200x80px) - Main DOMOVIK logo
  - Format: PNG or WebP
  - Max size: 200KB
  - Transparent background
  - Brand colors: Blue #006AAF, Orange #C6451F

### Donor Logos
- **donor-1.png** (150x60px) - First donor logo
- **donor-2.png** (150x60px) - Second donor logo
  - Format: PNG or WebP
  - Max size: 100KB each
  - Transparent background preferred

## Placeholder Strategy

Until real assets are provided, the template uses placeholder references:
- Domovik logo: `{% static 'images/logos/domovik-logo.png' %}`
- Donor logos: `{% static 'images/logos/donor-1.png' %}`, `donor-2.png`

**To add real logos:**
1. Place PNG/WebP files in this directory
2. Ensure filenames match exactly (case-sensitive)
3. Optimize images before upload (TinyPNG, Squoosh)
4. Test in browser to verify display
